# mdplayer

Веб-плеер онлайн-ТВ и архива передач для **iEdem TV (Edem / iLook)**. Работает по той же логике, что OttPlayer.
Сервер на Node.js запускается прямо на телефоне Android (через Termux), а смотреть можно в Chrome на этом же телефоне.

- Плейлист указывается один раз: ссылкой или файлом. Он сохраняется в `config.json`.
- Каналы разбиты по категориям (`group-title` / `#EXTGRP`). Есть логотипы, поиск и избранное.
- Программа передач (XMLTV, в том числе `.xml.gz`) скачивается сама по ссылке из `url-tvg` / `x-tvg-url`. Она кэшируется на диске и обновляется раз в 12 часов.
- **Архив**: нажатие на прошедшую передачу открывает её запись. Текущую передачу можно смотреть «с начала», кнопка «В эфир» возвращает к прямому эфиру.
- Встроенный плеер: HTML5 `<video>` + **hls.js 0.14.17** (последняя версия стабильной ветки 0.x, рассчитанной на старые браузеры).
- Кнопка ↗ открывает поток во внешнем плеере (VLC, MX Player).
- Никаких npm-пакетов: нужен только Node.js.

---

## 0. Вариант без Termux: приложение mdplayer.apk

Тот же mdplayer можно поставить как обычное приложение. Внутри APK работают Node.js 18 ([nodejs-mobile](https://github.com/nodejs-mobile/nodejs-mobile)) и сервер mdplayer, а интерфейс показывает встроенный WebView.
APK собирает GitHub Actions по файлу `.github/workflows/android.yml`. Android-оболочка лежит в папке `android/`.
Готовый файл появляется в разделе **Releases** репозитория. Сервер внутри APK слушает `127.0.0.1:8090`, поэтому не мешает версии в Termux.

## 1. Установка Node.js на Android 8 (Termux)

### 1.1. Установите Termux

Termux нужно ставить **не из Google Play**: там старая, неработающая версия. Подойдёт любой из двух источников:

- F-Droid: <https://f-droid.org/packages/com.termux/>. На странице есть кнопка «Скачать APK», ставить само приложение F-Droid не обязательно.
- GitHub: <https://github.com/termux/termux-app/releases>. Возьмите файл `termux-app_…_arm64-v8a.apk`. Для старого 32-битного телефона нужен `armeabi-v7a`, а если не знаете, какой у вас, берите `universal`.

Android попросит разрешить установку из неизвестных источников для браузера:
**Настройки → Приложения → Chrome → Установка неизвестных приложений → Разрешить**.

Запустите Termux и дождитесь окончания первичной установки (`Installing bootstrap packages…`).

### 1.2. Установите Node.js

В Termux выполните:

```sh
pkg update && pkg upgrade -y
pkg install nodejs-lts -y
node -v
```

Последняя команда должна показать версию, например `v20.x.x`. Если `pkg update` ругается на зеркала, выполните `termux-change-repo` и выберите другое зеркало.

### 1.3. Дайте Termux доступ к файлам телефона

```sh
termux-setup-storage
```

Разрешите доступ в появившемся окне. После этого папка «Загрузки» (Download) телефона будет видна в Termux как `~/storage/downloads`.

## 2. Копирование mdplayer на телефон

1. Скопируйте папку `mdplayer` с компьютера в папку **Download** телефона (по USB-кабелю, через облако или мессенджер).
2. Перенесите её в домашнюю папку Termux: там она работает быстрее и без проблем с правами.

```sh
cp -r ~/storage/downloads/mdplayer ~/mdplayer
```

Если вы передали архив `mdplayer.zip`, распакуйте его так:

```sh
pkg install unzip -y
unzip ~/storage/downloads/mdplayer.zip -d ~
```

## 3. Запуск

```sh
cd ~/mdplayer
node server.js
```

Появится сообщение:

```
mdplayer запущен
  Откройте в браузере:  http://127.0.0.1:8080
```

Откройте в **Chrome** на телефоне адрес **<http://127.0.0.1:8080>** (или `http://localhost:8080`).

Чтобы остановить сервер, нажмите в Termux `Ctrl` + `C` (клавиша CTRL есть в дополнительном ряду клавиатуры Termux).

### Первая настройка

При первом запуске откроются настройки.

1. Вставьте ссылку на ваш M3U8-плейлист из личного кабинета iEdem TV. Второй вариант: выберите «из файла» и укажите скачанный `.m3u8`.
2. Нажмите **«Сохранить»**. Сервер проверит плейлист, сохранит источник в `config.json` и загрузит каналы.
3. Программа передач скачается в фоне, ход загрузки виден в настройках (⚙). Для большого EPG первая загрузка может занять пару минут. После этого программа берётся из кэша, и перезапуск сервера проходит мгновенно.

Если в заголовке плейлиста нет `url-tvg`, используется `http://epg.it999.ru/edem.xml.gz`. Другой источник можно указать в поле «Программа передач».

## 4. Как пользоваться

| Где | Что делать |
|---|---|
| **Каналы** | Вверху категории, ниже поиск. Нажатие на канал включает прямой эфир. ☆ добавляет канал в «Избранное». Значок «↻ 3 д» означает, что у канала есть архив на 3 дня. |
| **Программа** | Вкладка «Программа» (или нажатие на строку под плеером). Вверху выбор дня. Значок **↻** означает, что запись есть в архиве: нажмите на передачу, чтобы её посмотреть. У идущей передачи есть «↻ с начала». |
| **В эфир** | Кнопка появляется при просмотре архива и возвращает к прямому эфиру. |
| **↗** | Открывает текущий поток во внешнем плеере (VLC, MX Player и т.п.). Пригодится, если встроенный плеер не справляется с каналом. |
| **⚙** | Настройки: источник плейлиста, EPG, прокси, выбор плеера, ручное обновление. |

Полноэкранный режим включается кнопкой в плеере. Если на телефоне включён автоповорот, достаточно повернуть его.
На планшете или телефоне, повёрнутом горизонтально, каналы показываются слева, а плеер и программа справа.

Совет: в меню Chrome выберите «Добавить на главный экран». На рабочем столе появится значок mdplayer.

## 5. Чтобы сервер не засыпал

- В уведомлении Termux нажмите **Acquire wakelock** (или выполните `termux-wake-lock`). Android не будет усыплять Termux.
- Отключите оптимизацию батареи для Termux: **Настройки → Приложения → Termux → Батарея → Не оптимизировать**. Названия пунктов зависят от производителя телефона.
- Termux можно свернуть: сервер продолжит работать, пока висит его уведомление.

Чтобы запускать сервер одним словом, выполните один раз:

```sh
echo 'alias mdp="cd ~/mdplayer && node server.js"' >> ~/.bashrc
source ~/.bashrc
```

Теперь достаточно открыть Termux и набрать `mdp`.

## 6. Просмотр с других устройств (телевизор, компьютер)

```sh
node server.js --host 0.0.0.0
```

Сервер покажет адрес в домашней сети, например `http://192.168.1.5:8080`. Его можно открыть на любом устройстве в том же Wi-Fi.
Потоки при этом идут через телефон, поэтому провайдер видит один IP-адрес.

> ⚠️ В этом режиме страницу (и вашу ссылку на плейлист) может открыть любой, кто подключён к этому Wi-Fi. Включайте его только дома.

Другой порт: `node server.js --port 8081`.

## 7. Настройки в config.json

Файл создаётся после первого сохранения в веб-интерфейсе. Его можно править и вручную, при остановленном сервере.

| Поле | Значение |
|---|---|
| `playlistSource` | `"url"` (по ссылке) или `"file"` (загруженный файл хранится в `data/playlist-upload.m3u8`) |
| `playlistUrl` | ссылка на плейлист |
| `epgUrl` | своя ссылка на XMLTV; пусто — взять из `url-tvg` плейлиста |
| `proxy` | `true` — потоки идут через сервер (нужно для hls.js, иначе браузер блокирует их из-за CORS) |
| `host`, `port` | адрес и порт сервера (по умолчанию `127.0.0.1:8080`) |
| `allowedHosts` | доменные имена, по которым разрешено открывать сервер (по IP и `localhost` можно всегда) |
| `userAgent` | свой User-Agent для запросов к провайдеру, если он нужен |

Папка `data/` хранит кэш: копию плейлиста, скачанный EPG (`epg-source.raw`) и разобранную программу (`epg.json`).
Удаление `data/` сбрасывает кэш, удаление `config.json` сбрасывает настройки.
Чтобы обновить mdplayer, замените файлы, но оставьте `config.json` и `data/`.

## 8. Как устроен архив

Сервер берёт параметры архива из плейлиста (`catchup`, `catchup-days`, `tvg-rec`, `catchup-source`). Когда вы нажимаете на передачу, он строит ссылку с её временем начала в формате Unix Timestamp (UTC):

| `catchup` в плейлисте | Ссылка на запись |
|---|---|
| `shift` / `append` без шаблона, или только `tvg-rec` (iEdem TV) | `ссылка_потока?utc=НАЧАЛО&lutc=СЕЙЧАС` |
| `append` + `catchup-source="?utc={utc}&lutc={lutc}"` | шаблон дописывается к ссылке потока |
| `default` + `catchup-source="http://…"` | шаблон и есть полная ссылка |
| `timeshift` | `ссылка_потока?timeshift=НАЧАЛО&timenow=СЕЙЧАС` |
| `flussonic` | `…/index-НАЧАЛО-ДЛИТЕЛЬНОСТЬ.m3u8` |

В шаблонах поддерживаются `{utc}`, `{start}`, `{utcend}`, `{end}`, `{lutc}`, `{now}`, `{timestamp}`, `{duration}`, `{offset}`, `{Y} {m} {d} {H} {M} {S}`, `{utc:Y-m-d:H-M-S}`, `{duration:60}` и вариант `${…}`.
Перед построением ссылки сервер проверяет, что передача уже началась и не старше глубины архива.

Каналы привязываются к программе передач сначала по `tvg-id`, затем по названию, а потом по названию без пометок HD/4K.
Если у канала есть архив, но нет программы, архив показывается по часам.

## 9. Если что-то не работает

| Симптом | Что сделать |
|---|---|
| «Нет связи с сервером mdplayer» | Сервер остановлен. Откройте Termux и запустите `node server.js`. |
| «Порт 8080 уже занят» | mdplayer уже запущен в другой сессии Termux. Можно запустить на другом порту: `--port 8081`. |
| «Доступ запрещён (HTTP 403)» | Проверьте ключ в ссылке и оплату подписки. Провайдер может пускать только с одного IP. |
| Чёрный экран или «Ошибка декодирования» | В ⚙ выберите «Встроенный HLS браузера» или откройте канал во внешнем плеере (↗). Обновите Chrome и «Android System WebView» в Google Play. |
| Программа не загружается, «Ни один канал не сопоставлен» | Укажите другую ссылку на XMLTV в поле «Программа передач» и нажмите «Обновить программу». |
| Передача из архива не открывается (404) | У провайдера нет этой записи. Архив хранится ограниченное число дней (`catchup-days`). |
| Нет логотипов | В плейлисте нет `tvg-logo`, а в EPG нет `<icon>`. Вместо логотипов показываются буквы. |

Все ошибки сервера выводятся в окне Termux.

## 10. Структура проекта

```
mdplayer/
├── server.js            HTTP-сервер: маршруты, запуск, адреса
├── lib/
│   ├── config.js        чтение и запись config.json
│   ├── http-client.js   загрузка по HTTP(S): редиректы, таймауты, gzip
│   ├── m3u.js           разбор M3U8 (группы, логотипы, параметры архива)
│   ├── playlist.js      плейлист по ссылке или из файла, резервная копия
│   ├── xmltv.js         потоковый разбор XMLTV (не держит файл в памяти)
│   ├── epg.js           загрузка, кэш и сопоставление программы с каналами
│   ├── catchup.js       построение ссылок на архив
│   ├── proxy.js         HLS-прокси (обход CORS, переписывание ссылок в m3u8)
│   ├── static.js        раздача public/, автозагрузка hls.js
│   ├── service.js       связывает всё вместе
│   └── api.js           REST API
└── public/              веб-интерфейс: ES5, чистые HTML/CSS/JS
    ├── index.html
    ├── css/style.css
    ├── js/              util, api, player, channels, epg, settings, app
    └── vendor/hls.min.js
```

Если `public/vendor/hls.min.js` потерялся, сервер сам скачает hls.js 0.14.17 с CDN при первом запуске.

### API

| Запрос | Ответ |
|---|---|
| `GET /api/state` | состояние: настроен ли плейлист, статус загрузки плейлиста и EPG |
| `POST /api/config` | сохранить настройки (`playlistSource`, `playlistUrl` или `playlistContent`, `epgUrl`, `proxy`) |
| `POST /api/refresh` | `{"what":"playlist"}` или `{"what":"epg"}` — обновить вручную |
| `GET /api/channels` | категории и каналы |
| `GET /api/now` | что идёт сейчас на каждом канале |
| `GET /api/epg?ch=ID` | программа передач канала |
| `GET /api/stream?ch=ID` | ссылка на прямой эфир |
| `GET /api/archive?ch=ID&start=UNIX&stop=UNIX` | ссылка на передачу из архива |
| `GET /proxy?u=URL` | HLS-прокси для плеера |
